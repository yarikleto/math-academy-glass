# Security reporting

Please report suspected vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/yarikleto/math-academy-glass/security/advisories/new).
If that form is unavailable, contact the creator through
[LinkedIn](https://www.linkedin.com/in/yarik-leto/). Do not open a public issue
containing sensitive vulnerability details.

Include the extension version, impact, and a minimal reproduction with synthetic
data. Do not send credentials, cookies, private lesson content, or browser
profiles. Avoid public exploit details until a fix can be reviewed.

Security fixes target the latest release. The extension has no backend,
analytics, remote executable code, or access to unrelated websites. Its
background broker validates message senders and stores only short-lived,
tab-partitioned state. See [PRIVACY.md](PRIVACY.md) for the data policy.
